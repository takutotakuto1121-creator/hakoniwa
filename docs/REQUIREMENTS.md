# hakoniwa 要件定義書

版: 1.1(2026-11-16)
対象: macOS 15 以降 / Apple Silicon(開発機: Apple M3, メモリ 8GB)

---

## 1. 目的

画面の中の小さな「箱庭」で、ニューラルネットの脳を持つ生き物たちが生まれ、食べ、戦い、増え、
世代を重ねて**誰も設計していない行動を自分で獲得していく**様子を眺められる macOS アプリを作る。

最優先の評価軸は **「人に見せて30秒で驚かれること」**。技術的な正しさはその土台として扱う。

### 1.1 見せ場(30秒デモ)

1. 起動直後: 何も考えていない生き物が、でたらめに泳ぎ回っている。
2. 早送りすると: 世代が数百・数千と進み、生き物の形と色が変わり、種が枝分かれしていく。
3. 進化した世界: 餌に一直線に向かう者、他者を追いかけて食べる捕食者、逃げる被食者、
   群れで動く者が現れている。
4. 1匹をクリック: その生き物の「脳」がリアルタイムに光り、何を見て何を判断しているかが見える。
   祖先をたどる系統樹で「この種は3時間前にこの祖先から分かれた」と分かる。

### 1.2 設計方針

- **行動は一切書かない。** 「餌に向かう」「逃げる」といった行動ルールはコードに存在せず、
  すべて脳の重みの進化から現れる。コードが決めるのは物理・代謝・感覚器・環境だけ。
- **エネルギー保存。** 世界の総エネルギーは一定で、植物 → 草食 → 肉食 → 死骸 → 土 と循環する。
  これにより人口が爆発も全滅もせず、生態系が長時間安定する。
- **観察できること自体が価値。** シミュレーションと同じ重さで、観察・可視化の道具を作る。
- **再現できること。** 同じシードと同じ版なら、スレッド数に関係なく同じ結果になる。

## 3. 世界のモデル

### 3.1 空間

- 2次元の矩形で、端がつながったトーラス状(端から出ると反対側から入る)。既定サイズは 4000×4000。
- 液体中のような抵抗があり、推進をやめると減速する(微生物・水槽の雰囲気)。
- 時間は固定刻み(1 tick = 1/20 秒の世界時間)。脳による判断は 2 tick に 1 回(10Hz)。

### 3.2 環境

- **肥沃度マップ**: ノイズで作る滑らかな濃淡。植物は肥沃な場所ほど多く生える。
- **季節**: 植物の成長速度が周期的に変わる。肥沃な場所もゆっくり移動し、移住を促す。
- **エネルギー**: 世界の総エネルギー量は一定。生き物の代謝で失われたエネルギーは「土」に戻り、
  植物として再び生える。

### 3.3 物体

| 物体 | 役割 |
|---|---|
| 植物 | 土のエネルギーから生える。動かない。草食に効率よく消化される |
| 死骸(肉) | 生き物が死ぬと体のエネルギーが肉片として残る。時間とともに腐って土に戻る |
| 卵 | 親が産む。一定時間後に孵化する。親のエネルギーの一部を持つ |
| 生き物 | 下記 |

## 4. 生き物

### 4.1 遺伝子(すべて子に受け継がれ、突然変異する)

| 遺伝子 | 影響 |
|---|---|
| 体の大きさ | 強さ・体力・エネルギー容量が上がるが、代謝と動きのコストも上がる |
| 食性(0=草食〜1=肉食) | 植物と肉の消化効率。中間は雑食だが両方とも効率が悪い |
| 体色(色相・彩度) | 見た目。他個体から見える(仲間の識別に使われうる) |
| 視野の角度・距離 | 広く遠く見えるほど維持コストがかかる |
| 最高速度・旋回力 | 動きの性能と、そのコスト |
| 産卵エネルギー | 卵1個に持たせるエネルギー(少産大卵 ↔ 多産小卵) |
| 突然変異率 | 子の遺伝子がどれだけ変わるか(それ自体も進化する) |
| 体の形 | 体節の数・ひれ・尾の長さ・模様。見た目と、わずかに速さ・旋回に影響 |
| 脳 | 結合の有無と重み(4.3) |

### 4.2 感覚(脳への入力)

- **視覚**: 視野を5つの扇形に分け、それぞれで「最も近い植物」「最も近い肉」「最も近い生き物」の近さを感じる。
  生き物については、相手の相対的な大きさ、自分との色の近さ(仲間らしさ)も感じる。
- **体内**: エネルギー残量、体力、年齢、現在の速さ、攻撃されているか。
- **音**: 周囲の個体が出す信号の強さ(2チャンネル)。
- **時計**: 体内の振動子(周期は遺伝子で決まる)。
- **定数**: バイアス入力。

### 4.3 脳

- 固定サイズの再帰型ニューラルネット(入力 約35 → 隠れ層 16(自分自身へ再帰)→ 出力 7)。
- 結合ごとに「有効/無効」の遺伝子を持ち、初期は疎な結合で始まる。結合の数に比例して維持コストがかかるため、
  不要な結合は進化で消えていく。これにより脳の図が読める程度に整理される。
- 再帰結合によって短期記憶を持てる。

### 4.4 行動(脳の出力)

| 出力 | 効果 |
|---|---|
| 前進 | 推進力。速いほどエネルギーを使う |
| 旋回 | 左右に曲がる |
| 噛みつく | 接触している相手にダメージ。肉食ほど強い。エネルギーを使う |
| 食べる | 接触している植物・肉を食べる |
| 産卵 | エネルギーが十分あれば卵を産む |
| 信号1・信号2 | 周囲に聞こえる信号を出す |

### 4.5 代謝・寿命

- 基礎代謝は体の大きさの 0.75 乗に比例(クライバーの法則)。
- 加えて、移動・攻撃・視覚・脳の結合数に応じたコストがかかる。
- エネルギーが尽きる、体力が尽きる、寿命を迎える、のいずれかで死に、体のエネルギーが肉として残る。
- 繁殖は無性生殖(卵)。突然変異のみで多様性を生む。

### 4.6 種

- 親から種を受け継ぐ。子の遺伝子が種の創始者から一定以上離れたら新しい種として分岐する。
- 種ごとに誕生時刻、絶滅時刻、親の種、個体数の推移を記録し、系統樹として表示する。
- 種には自動で名前(読める造語)が付く。

### 4.7 協力が生まれうる仕掛け

協力行動は保証しないが、進化しうる条件は用意する。

- 大きな獲物は1匹では倒しにくく、複数で噛むとダメージが重なる。肉は近くにいる全員が食べられる。
- 仲間の色が見えるため、「似た色は噛まない」「似た色の近くにいる」が進化しうる。
- 信号チャンネルで、合図による協調が進化しうる。

## 5. 画面と操作

### 5.1 画面構成

- **中央**: 世界の表示(パン・ズーム・追尾)。
- **上部バー**: 経過時間、最大世代、個体数、種の数、時間制御。
- **右パネル**: 選択中の個体の詳細(遺伝子、状態、脳のリアルタイム表示、祖先)。
- **下部パネル**(切り替え): 個体数グラフ(草食・雑食・肉食の内訳)、種の推移、系統樹、イベントログ。
- UI の言語は日本語。

### 5.2 表示

- 背景は暗い色で、植物・生き物がほのかに光る(ブルーム効果)。
- 生き物の形は遺伝子から作る。体節、ひれ、尾、目、模様を持ち、泳ぐと体がしなる。
- 肉食ほど鋭い形、草食ほど丸い形の傾向にする。
- 噛みつき・産卵・誕生・死亡に小さなエフェクトを付ける。

### 5.3 操作

| 操作 | 内容 |
|---|---|
| ドラッグ / スクロール / ピンチ | パン / ズーム |
| クリック | 個体を選択。ダブルクリックで追尾 |
| スペース | 一時停止・再開 |
| 数字キー 1〜5 | 速度(1×, 4×, 16×, 64×, 最大) |
| 介入ツール | 餌をまく、生き物を置く(選択個体の複製を含む)、取り除く、隕石(範囲内を全滅させる) |
| メニュー | 新しい世界(シード・世界の大きさ・初期個体数)、保存、読み込み、スクリーンショット、録画 |

## 6. 非機能要件

### 6.1 性能(Apple M3 / 8GB を基準)

| 項目 | 目標 |
|---|---|
| 描画 | 生き物 3,000 体・植物 20,000 個で 60fps |
| 早送り(画面あり) | 同条件で実時間の 30 倍以上 |
| ヘッドレス | 進化後の典型的な人口(約 1,600〜2,000 体)で実時間の 100 倍以上。3,000 体では 60 倍以上 |
| メモリ | 1 GB 以下 |
| 保存ファイル | 10 時間進化した世界で 5 MB 程度 |

> 改訂(1.1): 当初は「3,000 体で 100 倍」としていたが、実測では 3,000 体で約 60〜75 倍だった
> (感覚処理が支配的で、近傍探索の打ち切り・判断の間引き・データの詰め直しを入れた後の値)。
> 実際の生態系は 1,600〜3,000 体で推移し、その範囲で 1 時間に 60〜130 時間分の進化が進むため、
> 目標を実測に合わせて改めた。
| 起動 | 3 秒以内に生き物が動き出す |

### 6.2 品質

- 決定性: 同じシード・同じ版なら、スレッド数によらず同じ結果になる(テストで検証)。
- 安定性: ヘッドレスで 100 万 tick 回してクラッシュ・NaN・エネルギー収支の破綻がない(テストで検証)。
- 保存データは版番号を持ち、読み込めない版は明確なエラーを出す。
- シミュレーション部分は UI から独立したライブラリにし、単体テストを持つ。

### 6.3 技術

- Swift 6 / Swift Package Manager。外部ライブラリには依存しない(Apple 標準フレームワークのみ)。
- シミュレーション: マルチスレッドの CPU 計算(SIMD 利用)。空間ハッシュによる近傍探索。
- 描画: Metal(インスタンス描画、SDF による形状、ブルーム)。UI: SwiftUI + AppKit。
- 動画書き出し: AVFoundation。

## 7. 受け入れ基準

v1.0 の完成条件。各項目は自動テストかヘッドレス実行のログで確認する。

1. **進化の発生**: ランダムな初期状態から、ヘッドレスで世界時間 10 時間相当を進めると、
   「餌を見つけるまでの平均時間」が初期世代より明確に短くなる(第0世代比で半分以下)。
2. **捕食の発生**: 複数のシードのうち少なくとも一つで、肉食寄り(食性 0.7 以上)の系統が
   個体数の 5% 以上を占めて世界時間 1 時間以上存続する。
3. **生態系の安定**: 世界時間 10 時間の間に全滅せず、個体数が上限・下限に張り付かない。
4. **性能**: 6.1 の目標を満たす(ベンチマークコマンドで計測)。
5. **決定性・安定性**: 6.2 のテストがすべて通る。
6. **観察**: 個体選択・脳の可視化・系統樹・グラフ・イベントログが動作する。
7. **見せられる状態**: 事前に進化させた世界を同梱し、起動してすぐ「進化した生態系」を見せられる。
8. **配布**: `scripts/build-app.sh` 一つで `Hakoniwa.app` が作れ、ダブルクリックで起動する。

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 面白い行動が進化しない | 環境の圧力(餌の分布・季節・捕食の利得)をヘッドレスで多数のシードを回して調整する |
| 個体数が爆発・全滅する | エネルギー保存で上限を自然に決める。全滅時は最後の生存種から自動で再播種する |
| 性能が足りない | 近傍探索を空間ハッシュに、脳の計算を SIMD とマルチスレッドに。描画はインスタンス化 |
| 見た目が地味 | SDF で有機的な形、発光とブルーム、体のしなり、エフェクトに十分な時間を割く |
| 決定性が崩れる | 並列処理は「各個体が自分のことだけ書く」段階に限定し、相互作用は固定順で処理する |
